# Supermarket Sales Analysis Using Python

## Project Overview

This project analyzes supermarket sales data using Python.

The project focuses on data cleaning, exploratory data analysis (EDA),
data visualization, and extracting useful business insights from sales data.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Microsoft Excel

## Dataset

The dataset contains supermarket transaction information such as:

- Invoice ID
- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Total Sales
- Date
- Payment Method
- Customer Rating



## Project Objectives

- Understand the structure of the supermarket sales dataset.
- Check and handle missing values.
- Identify and remove duplicate records.
- Perform statistical analysis.
- Analyze sales by product line.
- Analyze sales by branch and city.
- Analyze different customer types.
- Analyze payment methods.
- Analyze customer ratings.
- Identify useful sales patterns and trends.
- Present the results using visualizations.

## Data Cleaning

The following data-cleaning activities were performed:

- Checked the dataset structure.
- Checked data types.
- Checked for missing values.
- Checked for duplicate records.
- Converted the Date column into a proper date format.
- Created additional columns for analysis.
